# Database

**Engine:** MySQL with InnoDB tables. The complete importable schema and sample data are in [`database/skillswap.sql`](../database/skillswap.sql).

## Import

Run `database/skillswap.sql` in MySQL or phpMyAdmin. The script creates the `skillswap` database if needed, selects it, drops existing tables in child-to-parent order, recreates the schema, and inserts sample data.

## Tables

### `users`

Stores SkillSwap accounts. The `role` values match the signup form: `earn`, `find-help`, and `both`.

| Column | Type | Constraints |
| --- | --- | --- |
| `id` | INT UNSIGNED | Primary key, auto-increment |
| `full_name` | VARCHAR(100) | NOT NULL |
| `email` | VARCHAR(150) | NOT NULL, UNIQUE |
| `password_hash` | VARCHAR(255) | NOT NULL; generated by PHP `password_hash()` |
| `role` | ENUM('earn','find-help','both') | NOT NULL |
| `created_at` | TIMESTAMP | NOT NULL, defaults to current time |

### `commissions`

Stores project requests posted by clients. Categories match the post form and browse filters.

| Column | Type | Constraints |
| --- | --- | --- |
| `id` | INT UNSIGNED | Primary key, auto-increment |
| `user_id` | INT UNSIGNED | NOT NULL, FK to `users.id`, `ON DELETE CASCADE` |
| `title` | VARCHAR(150) | NOT NULL |
| `category` | ENUM('Coding & IT','Arts & Design','Writing & Research','Tutoring & Review','Media & Content') | NOT NULL |
| `description` | TEXT | NOT NULL |
| `budget` | DECIMAL(10,2) | NOT NULL, greater than 0 |
| `deadline` | DATE | NOT NULL |
| `status` | ENUM('Open','In Progress','Completed') | NOT NULL, defaults to `Open` |
| `created_at` | TIMESTAMP | NOT NULL, defaults to current time |

### `applications`

Stores one application from a freelancer for a commission. The applicant name and email are obtained by joining `applications.user_id` to `users.id`; contact data is not duplicated.

| Column | Type | Constraints |
| --- | --- | --- |
| `id` | INT UNSIGNED | Primary key, auto-increment |
| `commission_id` | INT UNSIGNED | NOT NULL, FK to `commissions.id`, `ON DELETE CASCADE` |
| `user_id` | INT UNSIGNED | NOT NULL, FK to `users.id`, `ON DELETE CASCADE` |
| `proposal` | TEXT | NOT NULL |
| `proposed_rate` | DECIMAL(10,2) | NOT NULL, greater than 0 |
| `status` | ENUM('Pending','Accepted','Rejected') | NOT NULL, defaults to `Pending` |
| `created_at` | TIMESTAMP | NOT NULL, defaults to current time |
| `uq_one_application` | UNIQUE (`commission_id`, `user_id`) | One application per user per commission |

### `notifications`

Stores user-specific event messages for applications and completed commissions.

| Column | Type | Constraints |
| --- | --- | --- |
| `id` | INT UNSIGNED | Primary key, auto-increment |
| `user_id` | INT UNSIGNED | NOT NULL, FK to `users.id`, `ON DELETE CASCADE` |
| `commission_id` | INT UNSIGNED | NULL, optional FK to `commissions.id`, `ON DELETE CASCADE` |
| `type` | ENUM('application_received','application_accepted','application_rejected','commission_completed') | NOT NULL |
| `message` | VARCHAR(255) | NOT NULL |
| `is_read` | TINYINT(1) | NOT NULL, defaults to 0 |
| `created_at` | TIMESTAMP | NOT NULL, defaults to current time |

## Relationships

- `users` 1-to-many `commissions`: one user can post many commissions.
- `commissions` 1-to-many `applications`: one commission can receive many applications.
- `users` 1-to-many `applications`: one user can submit many applications.
- `users` 1-to-many `notifications`: one user can receive many notifications.
- `commissions` 1-to-many `notifications`: one commission can be linked to many notifications.
- `applications` has a unique `(commission_id, user_id)` pair, preventing duplicate applications.

The database does not enforce that an applicant differs from the commission owner. PHP rejects applications where `applications.user_id = commissions.user_id`.

Application acceptance and commission closing are coordinated by the service in a transaction. The resulting application and commission statuses, plus notification rows, are persisted together.

## Common queries

Use prepared statements in PHP for every query that accepts user input.

```sql
-- Open commissions with applicant counts.
SELECT c.*, COUNT(a.id) AS applicants
FROM commissions AS c
LEFT JOIN applications AS a ON a.commission_id = c.id
WHERE c.status = 'Open'
GROUP BY c.id
ORDER BY c.created_at DESC;
```

```sql
-- Applications per day for the dashboard's seven-day chart.
SELECT DATE(created_at) AS day, COUNT(*) AS total
FROM applications
WHERE created_at >= CURDATE() - INTERVAL 6 DAY
GROUP BY DATE(created_at)
ORDER BY day;
```

```sql
-- Notification list for the signed-in user.
SELECT n.*, c.title AS commission_title
FROM notifications AS n
LEFT JOIN commissions AS c ON c.id = n.commission_id
WHERE n.user_id = ?
ORDER BY n.created_at DESC;
```
